## 1. Introduction

The HB-2 is a digital dry block heater with interchangeable blocks. It is sold in two versions: the Single block and the Dual block, which has two independently controlled blocks.

Differences between the versions:

|  | Single block | Dual block |
| --- | --- | --- |
| Blocks | One block for 20 × 1.5 ml tubes | Two blocks, each for 20 × 1.5 ml tubes |
| Temperature control | One | Two, independent |
| Power | 150 W | 280 W |
| Warranty | 1 year | 2 years |

## 2. Safety

- The blocks reach 150 °C. Do not touch a hot block; use the block handle or wait until it is cool.
- Do not heat flammable liquids.
- Use only the blocks supplied with the unit, and do not use damaged blocks.
- Place on a heat-resistant surface with clear space around the unit.
- Switch off and unplug before changing blocks.

## 3. Setting up

1. Check the contents against the packing list.
2. Place the heater on a level, heat-resistant surface.
3. Fit the block(s) into the unit; no tools are needed.
4. Connect the mains cable (230 V AC, 50 Hz).

## 4. Operation

1. Switch on and set the temperature (Dual block: set each block separately).
2. Wait until the display shows the set temperature and allow about 10 minutes to stabilise.
3. Place the tubes in the block wells so they touch the bottom.
4. Set the timer if required and start the run.
5. Switch off and let the block cool before removing or cleaning.

## 5. Cleaning and maintenance

- Wipe the unit with a damp cloth when cool.
- Clean the block wells with a swab and 70 % ethanol.
- Do not immerse the unit in liquid.

## 6. Troubleshooting

| Problem | Likely cause | What to do |
| --- | --- | --- |
| Display shows an error | Over-temperature cut-out | Switch off, let the unit cool and restart |
| Temperature not reached | Block not seated | Reseat the block |
| Does not switch on | Mains cable not connected | Check the cable and socket |
